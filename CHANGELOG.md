# Changelog

## 0.1.0 (2026-11-20)

First public release.

- Road graph from OpenStreetMap or any centreline file, noded and projected automatically
- Premise attachment to the nearest road with split edges and lead-in distances
- Capacity-constrained splitter placement by road distance (capacitated network k-medoids)
- FDH cabinets housing several first-level splitters
- Shortest-path-tree routing for feeder, distribution and drop with shared trenches
- Per-segment cable sizing with spare fibres
- Per-premise optical loss budget against GPON class B+, C+ and C++
- Bill of materials with optional unit prices
- GeoPackage, KML, GeoJSON and CSV export, static and interactive maps
- `fttxplan demo | design | osm` command line
- Bundled real OSM sample area and a synthetic town generator
